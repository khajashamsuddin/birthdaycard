# A Little Birthday Surprise For Saniaa 🎀

A magical, aesthetic, story-driven birthday website created with pure HTML, CSS, and JavaScript.

## ✨ Features
- **Pure Web Technologies**: Pure HTML5, CSS3, and Vanilla JavaScript. No complex frameworks or build steps required.
- **7 Beautiful Interactive Chapters**:
  1. 🎀 Chapter 1: The Magic Envelope (Unfolding invitation for Saniaa)
  2. 🎂 Chapter 2: The Birthday Cake (Interactive candle blowing with smoke & confetti)
  3. 🌷 Chapter 3: Little Reminders (Interactive 3D flip cards)
  4. 💌 Chapter 4: 24 Birthday Wishes (Carousel with dot navigation & touch support)
  5. 🌻 Chapter 5: The Dua & Prayer Garden (Peaceful Islamic blessings & prayers)
  6. 🎁 Chapter 6: A Box of Sweet Compliments (Pop-up gift box with cute reminders)
  7. 🌙 Chapter 7: The Grand Keepsake Letter (Copyable letter, celebration confetti, replay)
- **Ambient Music Box**: Web Audio API music box chime melody.
- **100% Mobile Responsive**: Touch-friendly, swipe gesture support, and dynamic layout.

## 🚀 How to Run
Simply double-click `index.html` to open it directly in any browser (Chrome, Edge, Safari, Firefox), or serve it locally:

```bash
npm run dev
```

## 📁 File Structure
- `index.html` — The complete semantic structure and all 7 chapters.
- `style.css` — Dreamy pastel palette, responsive typography, and smooth CSS animations.
- `script.js` — Confetti engine, candle blowing, flip cards, wish carousel, and audio synthesis.
- `favicon.svg` — Cute ribbon favicon.
